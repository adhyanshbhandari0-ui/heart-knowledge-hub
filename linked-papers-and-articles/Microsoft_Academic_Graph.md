# Microsoft Academic Graph

**Source:** https://www.microsoft.com/en-us/research/project/microsoft-academic-graph

---

Editor’s note, May 4, 2021 – In a recent blog post , it was announced the Microsoft Academic website and underlying APIs will be retired on Dec. 31, 2021.

The Microsoft Academic Graph is a heterogeneous graph containing scientific publication records, citation relationships between those publications, as well as authors, institutions, journals, conferences, and fields of study. This graph is used to power experiences in Bing, Cortana, Word, and in Microsoft Academic . The graph is currently being updated on a bi-weekly basis until the end of the calendar year 2021. See our blog post for more information.

Microsoft Academic Graph (MAG) on Azure Storage (AS) For analytic and research usage scenarios, we offer an automated distribution service that uploads new versions of MAG to Azure Storage accounts. This option enables you to access the entire knowledge graph in an efficient and highly private manner. Please see Microsoft Academic Graph (opens in new tab) documentation for details. Microsoft Academic Knowledge API For demonstration and lightweight usage scenarios, we provide a REST-based Academic Knowledge API available through Cognitive Services Labs. The API is free, but there are a monthly quota and traffic throttles. The calls are routed through the public internet, and the callers have to share the resources.

For demonstration and lightweight usage scenarios, we provide a REST-based Academic Knowledge API available through Cognitive Services Labs. The API is free, but there are a monthly quota and traffic throttles. The calls are routed through the public internet, and the callers have to share the resources.

Microsoft Academic Knowledge Exploration Service (MAKES) MAKES is a portable version of the Academic Knowledge API that can be deployed and setup on private Azure subscriptions. Similar to MAG on AS, we offer an automated distribution service that uploads everything you need to setup and deploy Azure resources to host private instances of the Academic Knowledge API. The private instances are not rate limited and can be scaled up to more powerful hardware configurations based on required performance scenarios. Please see Microsoft Academic Knowledge Exploration Service (opens in new tab) documentation for details.
