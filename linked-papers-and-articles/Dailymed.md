These are pipe ( | ) delimited files relating SPL Set IDs with other information. Currently, there are three files: rxnorm_mappings.zip (SPL-RxNorm) pharmacologic_class_mappings.zip (SPL-Pharmacologic Class Mappings) dm_spl_zip_files_meta_data.zip (Zip File Metadata) To download these mapping files, please visit the SPL Resource Page for Mapping Files . The following diagram shows how they are related:

pharmacologic_class_mappings.zip (SPL-Pharmacologic Class Mappings)

dm_spl_zip_files_meta_data.zip (Zip File Metadata)

This file maps SPLs to the RxNorm concept(s) they represent. SPLs may represent multiple RxNorm concepts.

* For more information about these RxNorm terms, please visit RxNorm Overview .

SETID | SPL_VERSION | RXCUI | RXSTRING | RXTTY 897ad8b7-921d-eb02-a61c-3419e662a2da | 5 | 904458 | Pravastatin Sodium 10 MG Oral Tablet | SCD

This file maps SPLs to their Pharmacologic Class Indexing File(s). Pharmacologic Classes may contain multiple SPLs.

SPL_SETID | SPL_VERSION | PHARMA_SETID | PHARMA_VERSION 897ad8b7-921d-eb02-a61c-3419e662a2da | 5 | 0c41aa36-c7cc-4988-827f-c961252b5653 | 1

This file maps SPL Set IDs to their zip file name and drug title. For each SPL zip file name, there will be one and only entry in this file.

* For more information about Set ID, please visit www.fda.gov/downloads/ForIndustry/DataStandards/StructuredProductLabeling/UCM329269.pdf . If you do not have Adobe Acrobat, follow this link to download Adobe's free Acrobat Reader software . (Windows and Mac)
