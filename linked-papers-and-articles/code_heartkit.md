# code heartkit

**Source:** https://ambiqai.github.io/heartkit

---

Turn heart signals into on-device intelligence.

heartKIT is a Python AI development kit for building heart-monitoring applications on Ambiq devices. Train, evaluate and prepare ECG and PPG models for on-device use.

01 Prepare signals ECG and PPG dataset integrations

02 Build models Configurable architectures and training

03 Evaluate results Task metrics and saved experiments

04 Prepare for the edge Model export and task-level demos

heartKIT brings signal preparation, model development, evaluation and export into one Python workflow for ECG and PPG applications. Start with a built-in task and configuration, then change the data or model to fit the question you are working on.

You can run a configured workflow from the command line or use the Python API to assemble one yourself. The task pages explain each application; the guides walk through examples, and the API reference covers the underlying interfaces.
