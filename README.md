# Heart Knowledge Hub

One place for open-source tools, datasets and reading lists about the human heart
(ECG, HRV, cardiology AI).

| Folder | Original project | Topic |
|---|---|---|
| repos/awesome-ai-cardiology | cbailes/awesome-ai-cardiology | Curated list: AI in cardiology |
| repos/IntroECG | PierreElias/IntroECG | Intro to ECG deep learning |
| repos/cardio | analysiscenter/cardio | ECG analysis / deep learning toolkit |
| repos/awesome-hrv | mintisan/awesome-hrv | Curated list: heart rate variability |
| repos/NeuroKit | neuropsychology/NeuroKit | Physiological signal processing |
| repos/wfdb-python | MIT-LCP/wfdb-python | Read/write PhysioNet WFDB signals |
| repos/ecg | awni/ecg | Deep learning for ECG arrhythmia detection |
| repos/awesome-healthcare-datasets | geniusrise/awesome-healthcare-datasets | Curated healthcare datasets |
| repos/medical-data | beamandrew/medical-data | Medical datasets collection |

See [docs/external-resources.md](docs/external-resources.md) for datasets and papers.
